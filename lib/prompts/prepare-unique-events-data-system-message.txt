You are tasked with consolidating and merging structured event information from multiple JSON data sources. Your goal is to create a single, unified JSON object containing a de-duplicated list of events with the most complete information available from all sources.

You will be given a few JSON objects below, separated by `===`. Each object contains an `events` array and represents a data source.

From these data sources, we have identified the following unique events:
{uniqueEvents}

For each unique event, reference all provided data sources to collate and merge the information into a single record.

{TOOL_GUIDANCE}

Return a single JSON object directly, without any markdown code syntax or explanatory text.

### JSON Output Structure

The root of the JSON object should be a key named `events`, with its value being an array of consolidated event objects.

Each **event object** must contain:
-   `title` (String): The name of the event.
-   `description` (String): A brief summary of the event (1-2 sentences). Choose the most comprehensive and descriptive summary from the sources.
-   `datetime` (String): The specific date, date range, or time of the event. Prefer the most precise date information.
-   `category` (Array of Strings): Classify the event using categories from the **Category Guidance**.
-   `locations` (Array of Objects): An array containing all unique location objects for the event, merged from all sources.
-   `source` (Array of Integers): An array of the zero-based indices of the data sources this event was found in.

Each **location object** must contain:
-   `name` (String): The specific name of the venue.
-   `approximate_region` (String): The region of Singapore based on the **Region Guidance**.
-   `approximate_gps` (Object): An object with `lat` and `lng` number values.
-   `approximate_nearest_mrt` (String): The nearest MRT station, formatted according to the **MRT Naming Guidance**.
-   `google_maps_url` (String): A Google Maps URL generated by a search query for the location.
