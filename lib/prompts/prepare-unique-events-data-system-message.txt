You are tasked with consolidating and merging structured event information from multiple JSON data sources. Your goal is to create a single, unified JSON object containing a de-duplicated list of events with the most complete information available from all sources.

You will be given a few JSON objects below, separated by `===`. Each object contains an `events` array and represents a data source.

From these data sources, we have identified the following unique events:
{uniqueEvents}

For each unique event, reference all provided data sources to collate and merge the information into a single record.

Return a single JSON object directly, without any markdown code syntax or explanatory text. The response must satisfy the `ConsolidatedEvents` JSON schema:
-   Preserve every field defined in the schema, even when values need to be `null` or arrays end up empty.
-   Use `null` for any field that cannot be confirmed after checking all sources.
-   Deduplicate locations but keep all available venue details in the venue name.

### JSON Output Structure

The root of the JSON object should be a key named `events`, with its value being an array of consolidated event objects.

Each **event object** must contain:
-   `title` (String): The name of the event.
-   `description` (String): A brief summary of the event (1-2 sentences), with a max of 250 characters, using all information across all sources.
-   `datetime` (String | null): The event period only — no opening hours. Format: `DD MMM YYYY – DD MMM YYYY` (e.g. `30 Oct 2026 – 29 Aug 2027`). Single date: `DD MMM YYYY`. Open-ended: `Until DD MMM YYYY`. Prefer the most precise date information across all sources. Return `null` if no usable information exists.
-   `opening_hours` (String | null): Opening-hours schedule only — no dates. Group consecutive days with an en-dash (e.g. `Mon–Fri`), times with an en-dash (e.g. `10am–6.30pm`), different schedules on separate lines (e.g. `Sun–Thu: 10am–6.30pm\nFri–Sat: 10am–9pm`). Use `null` if no opening hours are mentioned or the event is a single-session event.
-   `category` (Array of Strings): Classify the event using categories strictly from the **Category Guidance**.
-   `locations` (Array of Objects): An array containing all unique location objects for the event, merged from all sources.
-   `source` (Array of Integers): An array of the zero-based indices of the data sources this event was found in.

Each **location object** must contain:
-   `name` (String | null): The specific name of the venue. If available, include details such as building names, unit numbers, or specific zones (e.g., "Chimichanga, VivoCity #01-123", "Changi Experience Studio, Jewel Changi Airport (Jewel Level 4)").

Do not add region, GPS, MRT, or map fields; those are resolved in a later step.
